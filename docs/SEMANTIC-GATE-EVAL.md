# 语义门控 A/B 实测记录

> 日期：2026-10-04 · 对象：HMEM `engine/retriever.py` 语义门控（Engram 上下文门控借鉴）
> 配置：`HMEM_GATE_ENABLED=true` `HMEM_GATE_TAU=0.1` `HMEM_GATE_FLOOR=0.5`
> 库：`/data/hmem-data/dev.db`（真实记忆库） · 模式：`use_rerank=True`（线上默认）

## 一、门控做什么（一句话）

词面（FTS）命中但语义跑题的候选，按语义相似度**折扣其得分**：

```
新分 = 原分 × clamp(hrr_sim / tau, floor, 1)      # tau=0.1, floor=0.5
```

- 语义相似度（`hrr_sim`，本地 HRR 相位相似度，无 API）**≥ 0.1** → 系数 = 1.0，**不动**
- **< 0.1** → 线性打折，最低打到 **0.5（对折，永不清零）**
- 无 HRR 信号 → 系数 = 1.0（安全，不误伤）

## 四、复现命令

```bash
# 环境：真实库 dev.db + rerank 模式（线上默认）
cd /data/codes/hmem/server
export EMB_KEY=$(tr '\0' '\n' < /proc/$(ss -ltnp | grep 8090 | grep -oP 'pid=\K[0-9]+' | head -1)/environ \
                 | grep '^EMBEDDING_API_KEY=' | cut -d= -f2-)
/data/codes/hmem/venv/bin/python - <<'PY'
import os, sys
sys.path.insert(0, "/data/codes/hmem/server")
from engine.store import HybridMemoryStore
from engine.retriever import HybridRetriever
from engine.embeddings import EmbeddingClient

ec = EmbeddingClient(base_url="http://localhost:3001/v1", api_key=os.environ["EMB_KEY"],
                     embedding_model="bge-m3", rerank_model="rerankv2m3")
s = HybridMemoryStore(db_path="/data/hmem-data/dev.db", embedding_dim=1024); s.initialize()
mk = lambda g: HybridRetriever(store=s, embedding_client=ec, keyword_weight=0.4,
        vector_weight=0.6, hrr_weight=0.4, gate_enabled=g, gate_tau=0.1, gate_floor=0.5,
        min_score=0.1)
q = "逆向 竞品"
for g in (False, True):
    print("gate=%s" % g)
    for r in mk(g).search(q, limit=5, use_rerank=True):
        print("  %.3f  %s" % (r["score"], r["content"][:50]))
s.close()
PY
```

## 五、结论

| 场景 | 门控行为 |
|---|---|
| 真相关内容（hrr ≥ 0.1） | 系数 = 1，**不动** |
| 词面重合但语义跑题（hrr < 0.1） | 按比例打折，最低 ×0.5（不清零） |
| 全库无语义匹配 | 全列均匀缩放，排序不变、召回不减 |

门控**只惩罚"词面碰巧重合"的跑题项**，不伤害真·相关内容；实测召回零损失、排序质量提升。
关闭方式：`HMEM_GATE_ENABLED=false`（行为退回改动前）。
